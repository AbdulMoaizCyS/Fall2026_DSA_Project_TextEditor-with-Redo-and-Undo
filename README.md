# Fall2026_DSA_Project_TextEditor-with-Redo-and-Undo
A console-based, line-based text editor written in C++.
Users can create and edit text line by line and reverse or repeat any change with undo and redo.
Built as the CS-222 Data Structures & Algorithms semester project at GIKI.
# Features
- Insert, edit, append and delete lines of text
- Display all lines with line numbers
- Undo and redo for every insert, edit, append and delete
- Save and open text files, with a warning about unsaved changes
- Login system with Editor and Admin roles
- Sort lines alphabetically
- Bracket checker for (), {} and []
- Search and replace across all lines
- Recent files list (last 5 files)
- Admin tools to list and delete users
